# Personal Finance Dashboard

## Project Overview
This project is designed for personal finance management and data visualization. The main objective is to track and analyze monthly income, savings, and expenses to gain insights into overall financial growth and spending habits.

## Data Source
The dataset is sourced from the `Finance_Database.xlsx` file, which contains structured monthly financial records spanning from January 2018 to January 2021 categorized as follows:
- **Income**: Salary, Secondary Income Sources
- **Savings**: Mutual Funds, Emergency Fund
- **Expenses**: Monthly living costs, personal expenses, and other expenditures

## Key Features & Visualizations
The Power BI report (`Personal_Finance_Dashboard.pbix`) includes the following key features:
- **Income vs. Savings Analysis**: Comparative monthly trends showing how savings scale relative to income over time.
- **Savings Allocation**: Detailed breakdown across Mutual Funds, Emergency Fund, and other investment channels.
- **Interactive Slicers**: Dynamic year and month filters for granular data exploration.

## Repository Contents
- `Personal_Finance_Dashboard.pbix` - Interactive Power BI report file.
- `Finance_Database.xlsx` - Raw dataset with categorized financial transaction data.

## Getting Started
1. Clone or download this repository.
2. Ensure you have **Power BI Desktop** installed on your system.
3. Open `Personal Finance Dashboard.pbix` in Power BI Desktop.
